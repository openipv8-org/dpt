Download dpt

dpt (Diagnostic Ports Time) is a network engineer's tool: ping, DNS and NTP time of an address, every DHCP server on the segment, mail servers, ports, routes, whois and RDAP, in one program for Windows, macOS and Linux. Open source, MIT licence. Source on GitHub.

Install

Linux and macOS: this checks the download against SHA256SUMS and puts dpt in /usr/local/bin, with its manual page (man dpt):

curl -fsSL https://raw.githubusercontent.com/openipv8-org/dpt/main/scripts/install.sh | bash

Or download the file for your system and run it with nothing after it: it installs itself, asking for sudo, or on Windows an Administrator prompt. Then dpt works in a new window, and dpt upgrade gets each new release.

The Windows builds are not code signed yet (see below), so Windows may warn about them, and Smart App Control blocks them.

Every release is built from this repository's source by GitHub Actions, and tested on a real machine of each of the six kinds above before it is published. A release is published only when all six pass.

Code signing policy

The Windows releases are to be signed through SignPath Foundation's free code signing for open source projects (applied for; the Windows builds are not signed yet). Once they are:

Only the files GitHub Actions builds from a release tag of this repository are signed: never a build made on someone's own machine. Every change goes through the repository's history, and every account that can change it uses two-factor authentication.

Privacy

dpt collects nothing and sends no telemetry. It talks to the network only when you run a command, and only to what that command is for:

CommandAsks
an address or name, ports, connect, trace, sweep, smtpthe address, host or network you give, and DNS servers to look up names
time tests, time, time native, infothe NTP servers time.google.com, time.windows.com, time.cloudflare.com (and those you name)
info, outside-ipifconfig.me, for the address the internet sees
whois, rdapIANA and the registry that holds what you ask about
upgrade, install <version>GitHub, for the release and its SHA256SUMS

On your own machine it keeps the interactive shell's history (~/.dpt_history) and the answers to smtp prompt (~/.dpt, which can hold a mail password: keep it private). Nothing of either leaves the machine.
